--------------

State belongs to the component. Props come from the parent.

A component re-renders when
 - its props change
 - its state change
 - its parent re-renders
 

Mount:
Component function runs → JSX rendered/committed → useEffect runs

Re-render (dependencies changed):
Component function runs again → JSX rendered/committed → previous useEffect cleanup runs → useEffect runs again

component re-renders
       ↓
effect dependencies checked
       ↓
dependencies changed?
    ↙          ↘
  YES           NO
   ↓             ↓
cleanup       nothing
   ↓
effect

Unmount:
useEffect cleanup runs → component is removed
